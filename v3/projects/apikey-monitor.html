APIキー漏洩候補の継続監視PoC

公開リポジトリのAPIキー漏洩候補を定期検出する、生キーを保存しないセキュリティPoC。

概要

検出アルゴリズムだけでなく、機密値を保持しないこと・定期実行を監視すること・人間承認を残すことが強み。

課題

公開リポジトリに紛れ込んだ秘密情報は、検出しても生キーを保存・通知する運用自体が新たなリスクになる。

解決 — 安全な検出フロー

検索→候補ハッシュ化→重複排除→人間レビュー、という安全フロー。raw keyを保存せず通知用表示値を分離。

主な機能・成果

  • Code Search / Repository Search・SQLite・日次/言語ローテーションのスイープ。
  • プロフィール公開メールとコミット由来メールを分けるなど通知前提の安全設計。
  • 定期実行・ダッシュボード掲載・非PII metricsを実装。
