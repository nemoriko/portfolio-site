upper · safe file ops

安全優先のファイル整理・データ復旧

速さより『元に戻せること・壊さないこと』を最優先したツール群。

概要

AIの自動化能力より、承認境界・停止条件・復元性を設計できることを示す事例です。セキュリティ・証拠保全・慎重な業務自動化で強く使えます。

課題

AIに整理や復旧を任せると、速さ優先で誤削除・元データ破壊が起きやすくなります。

解決 — 危険な一括削除 vs 5段階の安全ワークフロー

整理は scan / simulate / apply / restore の段階を分け、復旧は「修復より先にイメージ」「元媒体へ書き込まない」を固定原則にします。承認境界を挟み、対象外への移動は拒否、衝突時は停止します。

主な機能・成果

  • JSON正本と人間向けMarkdownを分け、対象フォルダ外への移動拒否・衝突時停止・ソフトデリート・MANIFESTによる復元を実装。
  • 復旧は読み取り専用診断 → イメージ化 → 複製解析の順。ドライブ番号だけを信用しない。
  • 機密辞書・媒体シリアル・生ログ・復旧ファイル一覧をGit履歴から分離。

失敗時にどう安全側へ倒したか

復旧の成功を保証する表現は避けます。成果は復旧件数ではなく、安全な切り分けと保全手順として示します。元媒体へは書き込まず、先にイメージを保全して複製側だけを解析します。
