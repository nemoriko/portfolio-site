AIエージェント開発・運用ハーネス

AIを単発のチャットではなく「安全に働き続ける開発チーム」として運用する自作基盤。他の全プロジェクトを支える中核です。

概要

AIに詳しくない人には「AIが前回までの仕事を覚える／危険な操作をしそうな時に止める／作業後に別のAIがチェックする／長時間処理が止まっていないか見張る／終わったら音で知らせる」仕組み、と説明できる運用基盤です。共通ルール・専門スキル・危険操作ガード・複数PC同期・長期記憶・無人実行・別AIレビュー・使用量の可視化・音声通知を、ひとつの運用体系にまとめています。

課題

単発チャットでは前回の文脈が毎回消え、危険操作の歯止めもなく、AIの自己採点だけでは思い込みを検出できません。研究コードのままでは、毎日の業務では電源・文字コード・二重起動などで静かに止まります。

解決 — 6層の運用フロー

「入力 → ルール/ガード → 記憶 → 実行 → 別AIレビュー → 通知」の層を、複数PCで再現できる一つの運用体系にまとめました。

主な機能・成果

  • 50件超のスキルと15件超のフックを、正本から複数PCへ配備する再現可能な構成。
  • SQLite FTS5（全文検索）と768次元ベクトル検索を組み合わせた長期記憶RAG。検索が役立った割合と誤誘導率まで測って注入件数を調整。
  • 無人実行は二重起動ロック・異常終了sentinel・watchdog・ログ監視・人間承認の二段ゲートを持つ。
  • 計画やコミットを別モデル（Codex / Opus / Gemini）で再確認し、単一AIの思い込みを抑える。
  • 共通ステータスバー・音声通知まで含む可観測性。機密度に応じてクラウドAIとローカルAIを使い分ける拡張層も準備。

失敗時にどう安全側へ倒したか

危険操作ガード・dry-run・復元導線・人間承認の二段ゲートを持ち、AIが破壊的操作をしそうな時に止めます。実際に止めた危険操作や、別AIレビューが指摘を返した例を証拠として示せます。自動化して終わりではなく、失敗を記憶とルールへ戻し、次回の再発防止に使います。
